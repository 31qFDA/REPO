# Обработчик анкет

Программа читает файл `anketa.txt`, проверяет ФИО, почту, телефон и группу,
выводит таблицу принятых анкет, список брака и статистику по группам.
Результаты сохраняются в `ok.txt` и `errors.txt`.

## Структура
- `main.py` — точка входа
- `validators.py` — проверки ФИО, почты, телефона, группы
- `report.py` — таблица, список брака, статистика

## Запуск
```
python main.py
```
Входной файл `anketa.txt` кладётся рядом с программой.
Формат строки: `ФИО;почта;телефон;группа`

## Результаты
- `ok.txt` — принятые анкеты
- `errors.txt` — отклонённые строки с причинами
