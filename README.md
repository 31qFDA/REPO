# Обработчик анкет

Программа читает файл `anketa.txt` со строками вида

    ФИО;почта;телефон;группа

проверяет ФИО, почту, телефон и группу, выводит таблицу принятых анкет,
список брака, статистику по группам и сохраняет результаты в
`ok.txt` и `errors.txt`.

## Модули

- `main.py`        — точка входа, порядок действий
- `validators.py`  — проверки ФИО, почты, телефона, группы
- `report.py`      — таблица, список брака, статистика

## Запуск

    python main.py

## Входной файл

`anketa.txt` в той же папке, что и `main.py`.
Одна анкета на строку, поля через `;`:

    Иванов Иван Иванович;ivanov@mail.ru;+7 900 123-45-67;ivt-21

## Выходные файлы

- `ok.txt`     — принятые анкеты
- `errors.txt` — отклонённые строки с причинами
